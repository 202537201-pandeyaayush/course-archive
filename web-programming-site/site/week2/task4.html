Frequently Asked Questions

What is semantic HTML?

Semantic HTML means choosing elements based on their meaning (like <nav> or <article>), not just their visual appearance.

Why should I use semantic elements instead of divs?

Semantic elements improve accessibility, SEO, and code readability by telling browsers and screen readers what each part of the page actually means.

What's the difference between section and article?

An <article> is self-contained and could stand alone; a <section> needs its surrounding page context to make sense.

Do I need a doctype on every HTML page?

Yes — <!DOCTYPE html> tells the browser to render the page in standards mode instead of quirks mode.
