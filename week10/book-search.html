How it works

1. Search input

Enter a book title or author and choose the search type.

2. Fetch API

JavaScript builds a query URL and retrieves JSON with async/await.

3. Display results

Each card shows its title, author, first publication year, cover when available and catalogue link.

4. Handle states

Loading, no-result, error and pagination messages are displayed.
