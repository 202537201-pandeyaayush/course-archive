# Week 11_1 — Aayush Pandey

React components and props coursework for Gachon University Web Programming.

## Included
- Profile cards with props and avatar fallback
- Filterable notification list with conditional icons
- Reusable card using `children`
- Student directory using five props
- Technology-filtered project gallery
- Additional practice: default props, product stock status, keyed lists, and conditional sign-in UI

## Run locally
```bash
npm install
npm run dev
```

## Build for GitHub Pages
```bash
npm run build
```
The project root `index.html` redirects to the included `dist/index.html` build. Upload the complete project folder as `week11_1/` in your course archive.
