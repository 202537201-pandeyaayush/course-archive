# Week 5 — JavaScript Practice

This folder contains the Week 5 activities shown in the course archive screenshots.

## Files

- `index.html` — Counter App (add, subtract, reset)
- `conditions.html` — Grade Checker using `if / else if / else`
- `loops.html` — Run a `for` loop and a `for...of` loop
- `txt.html` — Basic HTML text practice
- `style.css` — Shared responsive styles
- `counter.js`, `conditions.js`, `loops.js` — JavaScript for the activities

## Add to GitHub

Upload the complete `week5` folder to the root of your `course-archive` repository. Keep the filenames lowercase. If your main archive page has a Week 5 tab or list, link it to `week5/index.html`.
