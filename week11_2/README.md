# Week 11_2 — Aayush Pandey

React state and events coursework for Gachon University Web Programming.

## Included
- Counter with functional state updates
- Controlled text input and live preview
- Add/remove list items
- Conditional show/hide content
- Completed-task toggles and filters
- Controlled profile form with validation
- Note saved to browser localStorage with `useEffect`

## Run locally
```bash
npm install
npm run dev
```

## Build for GitHub Pages
```bash
npm run build
```
The project root `index.html` redirects to the included `dist/index.html` build. Upload the complete project folder as `week11_2/` in your course archive.
