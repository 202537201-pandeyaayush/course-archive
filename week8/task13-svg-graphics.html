What is SVG?

SVG stands for Scalable Vector Graphics. It is an XML-based image format that describes graphics using shapes, paths, lines, colors and text. Unlike pixel-based images, SVG graphics can be enlarged or reduced without becoming blurry.

Key idea: SVG is useful for logos, icons, diagrams, charts and illustrations that need to stay sharp at different screen sizes.

Common SVG shapes

1. Rectangle and circle

2. Ellipse and line

3. Polygon

4. SVG text

Example SVG code

This example draws a circle. The viewBox defines the coordinate system, fill sets the inside color and stroke sets the outline.

<svg viewBox="0 0 120 120" role="img"
     aria-label="Blue circle">
  <circle cx="60" cy="60" r="42"
          fill="#2454b8"
          stroke="#17233f"
          stroke-width="4" />
</svg>

SVG compared with PNG and JPG

PNGRasterScreenshots and images needing transparencyCan become pixelated when enlarged
JPGRasterPhotographs and complex imagesCan become pixelated when enlarged

Why use SVG?

  • Resolution-independent and sharp on high-density displays.
  • Shapes and colors can be styled with attributes or CSS.
  • SVG can be embedded directly in an HTML document.
  • Accessible names can be added with title and ARIA labels.

For photographs, JPG, PNG, WebP or AVIF are usually more suitable. SVG is most useful for graphics made from shapes and paths.
