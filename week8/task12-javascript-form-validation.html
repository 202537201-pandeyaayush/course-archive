What is JavaScript form validation?

Form validation checks whether information entered by a user follows the rules required by an application. HTML attributes such as required are useful, but JavaScript lets us create custom rules and display our own feedback.

Try it: Submit the form with empty fields, an invalid email, a short password, or passwords that do not match. Correct the values and submit again.

Interactive registration form

Front-end demonstration only. It validates fields in your browser and does not send or store your information.

Validation rules

  • Full name: must not be empty.
  • Email: must match a basic email format.
  • Password: at least 8 characters, including a letter and a number.
  • Confirm password: must match the password.

How the JavaScript works

form.addEventListener("submit", function(event) {
  event.preventDefault();
  // Read values, check each rule, and show errors.
  // Continue only when every field is valid.
});

The submit event listener runs when the user submits the form. preventDefault() stops normal submission while custom checks run.
