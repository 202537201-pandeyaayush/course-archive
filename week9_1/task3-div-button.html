Div Button
vs. Native Button.

Compare a generic clickable element with a semantic button that supports keyboard operation.

TASK 03

Student: Pandey Aayush  ·  Student ID: 202537201

1. Why a clickable div is a problem

A generic div is not a button. Adding a mouse click handler does not automatically make it keyboard-focusable or give it the expected button behavior.

2. Before and after comparison

Before — generic div

The element below responds to a mouse click only.

3. Keyboard and focus test

Press Tab to move to the native button. Its yellow outline indicates keyboard focus. Press Enter or Space to activate it.

Waiting for activation.

4. Code comparison

Before

<div onclick="submitForm()">Submit form</div>

After

<button type="button" onclick="submitForm()"> Submit form </button>

Use native HTML controls whenever possible. They provide standard keyboard behavior and semantics.

5. Conclusion

A native button is easier to operate with a keyboard and assistive technology than a generic clickable div. It also provides expected focus and activation behavior without needing custom keyboard scripting.
