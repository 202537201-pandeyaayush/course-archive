WEEK 09 · PART 1 · TASK 03

Div vs. Native
Button.

Compare a generic clickable element with a semantic button that supports keyboard operation and assistive technology.

TASK 03

Student: Aayush Pandey  ·  Student ID: 202537201

1. Why semantics matter

A div is a generic container. Adding an onclick handler does not automatically make it focusable, announce it as a button, or provide standard Enter/Space activation. A native button provides these behaviors by default.

2. Before-and-after comparison

Before · generic div

This element responds to a mouse click but is not in the normal keyboard tab order.

Submit form

Try pressing Tab: this generic div is skipped.

<div onclick="submitForm()">
  Submit form
</div>
After · native button

This semantic button supports keyboard focus and activation.

Use Tab, then press Enter or Space.

<button type="button"
  onclick="submitForm()">
  Submit form
</button>

3. Keyboard test

Use the Tab key to reach the button below. Confirm that the visible focus outline appears, then press Enter or Space.

Waiting for activation.

4. What to remember

  • Choose an element based on its meaning, not just its appearance.
  • Use a native button for an action and an anchor for navigation.
  • Keep a visible keyboard focus indicator.
  • Use custom keyboard handling only when a native semantic element cannot meet the requirement.
