What this demonstrates

async / await

Waits for the network response and then for JSON parsing without freezing the whole page.

res.ok

Checks whether the HTTP status is successful (200–299). A 404 does not automatically reject fetch().

try / catch

Catches network errors and errors we throw when the response status is not successful.

finally

Always hides the spinner and re-enables the button, whether the request succeeds or fails.
