First rule: semantic HTML before ARIA

ARIA supplements native HTML; it should not replace an appropriate native element.

<nav aria-label="Main navigation">
  ...
</nav>

<button type="button"
        aria-expanded="false"
        aria-controls="details"
        id="toggle-details">
  Show details
</button>
<section id="details" hidden>
  Additional information.
</section>

<span aria-hidden="true">★</span>
<span>Rated 4.8 out of 5</span>

Expanded content. The button's visible state and aria-expanded value are updated together.

  • aria-label provides an accessible name when visible text is not available.
  • aria-hidden="true" hides redundant/decorative content from the accessibility tree, not from the screen.
  • aria-expanded communicates a disclosure widget’s open/closed state.
