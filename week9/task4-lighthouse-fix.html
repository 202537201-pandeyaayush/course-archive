Task 04

Lighthouse Fix

Chrome Lighthouse can audit accessibility, performance, best practices, and SEO. This exercise focuses on common accessibility findings.

Common findings and fixes

  • Image elements do not have [alt] attributes: add meaningful alt text or alt="" for decorative images.
  • Form elements do not have associated labels: connect a label using matching for and id.
  • Background and foreground colors do not have sufficient contrast: choose colors that meet WCAG contrast guidance.
  • Links do not have a discernible name: give each link meaningful text.

Try a labeled form field


To run Lighthouse: open Chrome DevTools → Lighthouse → select Accessibility → Analyze page load.
