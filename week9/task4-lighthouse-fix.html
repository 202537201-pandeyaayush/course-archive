Sample Lighthouse findings

Lighthouse can identify several automated accessibility issues. It cannot prove that a page is fully accessible, so combine the report with manual keyboard and screen-reader checks.

FindingLikely causeFix
Buttons do not have accessible namesIcon-only button with no labelAdd visible text or aria-label
Form elements do not have labelsPlaceholder used instead of labelUse label and matching id
Links have no discernible nameEmpty link or image without altGive the link descriptive text
Background and foreground colors lack contrastText color too close to backgroundChoose a contrast-compliant pair

Retest workflow

  1. Open the deployed page in Chrome.
  2. Run Lighthouse from DevTools → Lighthouse.
  3. Record the URL, date, device mode and score.
  4. Fix the listed issues one by one.
  5. Run the audit again and compare results.
  6. Manually test keyboard navigation and labels.
A successful fix is one that improves the real user experience, not just the score.
