Task 01

Accessibility Audit Report

An accessibility audit checks whether people can use a page with different devices and assistive technologies. Review the sample page below and note what should be improved.

Sample page to audit

Continue

This text has very low contrast.

Audit checklist

  • Does every meaningful image have useful alternative text?
  • Are controls real buttons or links?
  • Can the page be used with a keyboard?
  • Is text contrast strong enough?
  • Do form fields have visible labels?

Expected findings: missing image alternative text, clickable non-button element, low contrast, and an unlabeled input.
