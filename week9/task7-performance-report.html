Performance overview

Web performance affects how quickly content appears, how responsive the page feels and whether the layout remains stable. This report uses the Core Web Vitals framework.

LCPLargest Contentful Paint — loading
INPInteraction to Next Paint — responsiveness
CLSCumulative Layout Shift — visual stability
TTFBTime to First Byte — server response diagnostic

Reference: web.dev — Web Vitals.

Assessment and improvement plan

AreaPotential issueRecommended action
ImagesLarge images delay the main contentResize, compress, use WebP/AVIF and set dimensions
JavaScriptLarge scripts delay interactionRemove unused code, split bundles and defer non-critical scripts
FontsLate font loading changes text layoutUse fewer font weights and preload only critical fonts
LayoutImages or ads shift contentReserve width and height or aspect-ratio space
ServerSlow initial responseEnable caching and review hosting/server response

Record your real test results

Enter the values from PageSpeed Insights or Lighthouse. These fields are intentionally blank so the report does not claim measurements that were not collected.
