Task 07

Performance Report

A performance report explains how quickly a page loads, responds, and becomes visually stable. Core Web Vitals provide useful user-centered measurements.

Key metrics

  • LCP — Largest Contentful Paint: loading performance.
  • INP — Interaction to Next Paint: responsiveness to interactions.
  • CLS — Cumulative Layout Shift: visual stability.

Other useful diagnostics include total blocking time, image sizes, unused JavaScript, and render-blocking resources.
