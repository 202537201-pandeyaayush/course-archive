Adding Defer.

Demonstrate how the defer attribute downloads an external script without blocking HTML parsing.

What does defer do?

For a classic external script, defer lets the browser continue parsing HTML while the script downloads. The script executes after parsing is complete and before the DOMContentLoaded event. Deferred scripts keep document order.

Blocking script
<script src="app.js"></script>

HTML parsing pauses while the script is fetched and executed.

Deferred script
<script src="app.js" defer></script>

HTML parsing continues; execution happens after parsing.

Do not add defer to inline classic scripts. Module scripts are deferred by default.
