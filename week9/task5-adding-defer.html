Task 05

Adding Defer

By default, a classic external script can pause HTML parsing while it downloads and executes. The defer attribute downloads the script in parallel and runs it after HTML parsing is complete.

Compare the script tags

<!-- May block HTML parsing -->
<script src="app.js"></script>

<!-- Downloads in parallel; runs after parsing -->
<script src="app.js" defer></script>

Remember: deferred classic scripts execute in document order and run before DOMContentLoaded.

Use defer for external classic scripts that depend on the parsed document. Module scripts are deferred by default.
