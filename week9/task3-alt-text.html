Task 03 of 06

Choose alt text by purpose

  • Informative image: describe the useful information and purpose.
  • Decorative image: use alt="" so screen readers can skip it.
  • Functional image inside a button: describe the action, such as “Search”.
<!-- Informative -->
<img src="enrollment-chart.png"
     alt="Enrollment rose 40% from 2024 to 2026">

<!-- Decorative -->
<img src="divider.svg" alt="">

<!-- Image used as a button's label -->
<button type="button">
  <img src="search.svg" alt="">
  Search
</button>

Avoid alt text like “image of…” or “photo of…”. If an image conveys no information and has no function, use an empty alt attribute rather than omitting alt entirely.

Practice

Review every <img> on your project. Add meaningful alt text, or alt="" for purely decorative images.
