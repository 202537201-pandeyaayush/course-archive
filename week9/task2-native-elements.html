Task 02 of 06

Use the right element

Use <button> for an action and <a href> for navigation. A clickable <div> does not automatically support keyboard focus, Enter/Space, or a button role.

<!-- Action -->
<button type="button" id="demo-button">Show message</button>
<p id="demo-message" aria-live="polite"></p>

<!-- Navigation -->
<a href="../index.html">Back to course archive</a>

The demo message will appear here.

  • Tab should focus the button.
  • Enter and Space should activate it.
  • Links should navigate to a real destination.
