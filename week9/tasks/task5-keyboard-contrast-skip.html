Task 05 of 06

Keyboard test

Put the mouse aside and test your site using only the keyboard:

  • Tab / Shift+Tab: move forward and backward through focusable controls.
  • Enter: activate links and buttons.
  • Space: activate buttons and toggle checkboxes.
  • Arrow keys: navigate controls such as radio groups and menus where expected.
  • Escape: close dialogs and dropdowns where expected.

Color contrast

WCAG 2.1 Level AA requires at least 4.5:1 contrast for normal text. Large text generally needs at least 3:1. Check colors with the WebAIM Contrast Checker or Chrome DevTools.

Add a skip link

Place this as the first focusable item inside <body>, and ensure the main content has the matching ID.

<body>
  <a class="skip-link" href="#main-content">
    Skip to main content
  </a>

  <nav aria-label="Main navigation">...</nav>

  <main id="main-content">
    ...
  </main>
</body>
.skip-link {
  position: absolute;
  left: -9999px;
  top: .5rem;
}
.skip-link:focus {
  left: .5rem;
  z-index: 9999;
  background: #17213b;
  color: white;
  padding: .5rem 1rem;
}

Test: reload the page and press Tab once. The skip link should become visible. Activate it and confirm focus/navigation reaches the main content.
