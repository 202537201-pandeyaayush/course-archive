Performance Test Page

This page contains a simple interaction you can test. Use browser DevTools or Lighthouse to measure it under consistent conditions.

Interaction test

Activate the button to test interaction response.

Testing procedure

  1. Open this page in Chrome.
  2. Open DevTools and select the Performance or Lighthouse panel.
  3. Run a test under a consistent device and network profile.
  4. Record LCP, INP (or the available interaction diagnostic), and CLS.
  5. Make one optimization and run the test again.

A single local test is not a universal performance score. Repeat tests and compare results under the same conditions.
