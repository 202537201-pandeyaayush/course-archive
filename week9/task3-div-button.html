Task 03

Div Button

A div is a generic container. It does not automatically behave like a button for keyboard and assistive-technology users. Use a native button for actions.

Not recommended:

Click div

Recommended:

<button type="button" onclick="saveChanges()">Save changes</button>

Native buttons support keyboard activation and expose their role to assistive technologies automatically.
