Image format comparison

Choose a format based on image content, compression, transparency, animation and browser support. Modern formats can reduce file size, but a fallback may be useful for compatibility.

FormatCompression / strengthsBest useWatch out for
JPEGLossy; widely supportedPhotographsNo transparency; repeated edits can reduce quality
PNGLossless; transparencyScreenshots, diagrams and sharp graphicsOften larger than modern alternatives
WebPLossy and lossless; transparency and animationGeneral web imageryKeep fallback if your target environment needs it
AVIFHigh compression; supports transparency and animationPhotographs where supportedEncoding can be slower; test compatibility
SVGVector; scales without pixelationIcons, logos and simple illustrationsNot suitable for photographs

Reference: MDN image format guide.

Picture element with fallback

<picture>
  <source srcset="campus.avif" type="image/avif">
  <source srcset="campus.webp" type="image/webp">
  <img src="campus.jpg"
       alt="University campus building"
       width="800" height="500">
</picture>
The browser selects the first supported source. The img element provides the fallback and alternative text.
