Task 06

Comparing Image Format

Image format affects file size, visual quality, transparency, and browser support. The best choice depends on the image and how it will be used.

Format comparison

  • JPEG: good for photographs; lossy compression; no transparency.
  • PNG: lossless; supports transparency; often larger for photos.
  • WebP: modern format supporting lossy/lossless compression and transparency.
  • AVIF: often very efficient compression; useful for modern web delivery.
  • SVG: vector format ideal for logos and icons.
